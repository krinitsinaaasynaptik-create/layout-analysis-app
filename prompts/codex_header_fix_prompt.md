# Исправить верхнюю плашку страницы

Используй второй скрин как источник истины. Первый скрин — это неправильный результат, его нужно исправить.

Сейчас верхняя плашка страницы сверстана неправильно: она слишком высокая, растянута почти как hero-блок, а кнопки расположены вертикально справа.

Нужно привести верхнюю плашку к макету из Figma.

---

## Как сейчас неправильно

Сейчас header выглядит так:

- очень высокая белая карточка;
- большой вертикальный отступ сверху и снизу;
- кнопки справа стоят в колонку;
- заголовок находится слишком высоко и далеко от кнопок;
- блок занимает слишком много места на первом экране.

Так делать не нужно.

---

## Как должно быть

Header должен быть компактной горизонтальной плашкой высотой примерно `64–72px`.

Структура:

```text
[Киров · Управленческий обзор]
[Аналитика рынка]                         [Рынок] [Все планировки] [CSV]
```

То есть:

- слева находится текстовый блок с контекстом и заголовком;
- справа находятся кнопки навигации;
- кнопки стоят в одну горизонтальную строку;
- вся плашка невысокая;
- внутри плашки нет лишнего воздуха;
- header похож на компактную toolbar-карточку, а не на hero section.

---

## Требования к верстке

Сделать header одной белой карточкой на сером фоне.

```css
.page-header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  min-height: 64px;
  padding: 14px 20px;
  background: #ffffff;
  border-radius: 16px;
  box-shadow: none;
}
```

Важно:

- НЕ использовать большую высоту типа `180px`, `200px`, `min-height: 200px`;
- НЕ располагать кнопки вертикально;
- НЕ делать отдельный hero-блок;
- НЕ растягивать header по высоте;
- НЕ добавлять большие `padding-top` / `padding-bottom`.

---

## Левая часть header

Слева должен быть блок:

```text
Киров · Управленческий обзор
Аналитика рынка
```

CSS:

```css
.header-left {
  display: flex;
  flex-direction: column;
  justify-content: center;
  gap: 4px;
}

.header-context {
  font-size: 12px;
  line-height: 16px;
  font-weight: 500;
  color: #667085;
}

.header-title {
  font-size: 24px;
  line-height: 30px;
  font-weight: 700;
  color: #101828;
  margin: 0;
}
```

---

## Правая часть header

Справа кнопки должны быть в одну строку:

```text
[Рынок] [Все планировки] [CSV]
```

CSS:

```css
.header-actions {
  display: flex;
  align-items: center;
  gap: 12px;
}
```

Кнопки:

```css
.header-button {
  height: 38px;
  min-width: 132px;
  padding: 0 24px;
  border-radius: 14px;
  border: 1px solid #D0D5DD;
  background: #F3F4F6;
  color: #101828;
  font-size: 14px;
  line-height: 20px;
  font-weight: 600;
  box-shadow: none;
}
```

Для кнопки CSV можно оставить меньшую ширину:

```css
.header-button-small {
  min-width: 104px;
}
```

Hover:

```css
.header-button:hover {
  background: #E5E7EB;
}
```

Активная кнопка:

```css
.header-button-active {
  background: #EDEFF3;
  border-color: #D0D5DD;
}
```

---

## Размеры и отступы

Обертка страницы:

```css
.page {
  background: #EDEDED;
  padding: 12px;
}
```

Header:

```css
.page-header {
  width: 100%;
  min-height: 64px;
  box-sizing: border-box;
}
```

Внутри header:

- вертикальные отступы не больше `14–16px`;
- горизонтальные отступы `20–24px`;
- расстояние между кнопками `10–12px`;
- кнопки не должны переноситься на новую строку на desktop.

---

## Desktop-раскладка

На desktop header должен быть в одну строку:

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ Киров · Управленческий обзор                 [Рынок] [Все планировки] [CSV] │
│ Аналитика рынка                                                               │
└──────────────────────────────────────────────────────────────────────────────┘
```

---

## Адаптив

На tablet можно оставить так же, если помещается.

На mobile:

- header может стать вертикальным;
- кнопки могут уйти во вторую строку;
- но на desktop кнопки обязательно должны быть горизонтально справа.

Mobile CSS:

```css
@media (max-width: 768px) {
  .page-header {
    flex-direction: column;
    align-items: stretch;
    gap: 16px;
  }

  .header-actions {
    width: 100%;
    display: grid;
    grid-template-columns: 1fr;
    gap: 8px;
  }

  .header-button {
    width: 100%;
  }
}
```

---

## Что проверить после исправления

1. Header стал компактным, примерно как в макете.
2. Кнопки справа стоят горизонтально.
3. Высота header не похожа на hero-блок.
4. Заголовок и контекст слева выровнены по центру высоты плашки.
5. Нет больших пустых областей сверху и снизу.
6. Белая карточка header лежит на сером фоне.
7. Радиус карточки соответствует макету.
8. Стиль применен ко всем страницам, где используется такой header.

Главное: верхняя плашка должна быть не отдельным большим баннером, а компактной навигационной карточкой.
